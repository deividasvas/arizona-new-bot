# ARIZONA SURPRISE NEW BOT DISCORD.JS V14

1. Структура
    index.js[файл] - файл в котором происходит инициализация и запуск бота.
    modules[папка] - модули для работы с interactionCreate, и ручные модули.
    events[папка] - события discord'a которые провоцируются пользователем(отправка сообщения, удаление сообщения, нажатия кнопки и т.п).
    configs[папка] - разного рода настройки для бота
        settings.js[файл] - файл с базовыми настройками токена, ролей, каналов, и т.п.
    components[папка] - компоненты которые могут быть задействованы во всём боте.
    commands[папка] - папка с категориями команд
